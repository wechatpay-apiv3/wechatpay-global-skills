## 微信支付境外 Skills

微信支付为 AI Agent 提供了专业的境外（跨境）接入技能包（Skill），将 WeChat Pay Global 的业务知识、产品选型规则、代码示例导航和接入规范，以 Agent 可理解的方式组织起来，使 Agent 能够准确地协助开发者完成**境外微信支付**的接入工作。

> 💡 **境内 ≠ 境外**：本 Skill 只服务境外接入（域名 `apihk.mch.weixin.qq.com`、路径前缀 `/v3/global/`）。如果你接入的是境内业务，请改用 [`wechatpay-basic-payment`](../wechatpay-basic-payment/SKILL.md)。

### Skill 列表

| Skill | 说明 |
| --- | --- |
| [wechatpay-global-payment](./SKILL.md) | 微信支付境外（跨境）平台全产品接入指引 |

> 💡 **推荐使用 `wechatpay-global-payment`**：这是微信支付境外接入的统一入口 Skill，覆盖 7 大支付产品 + 跨境分账 / 子商户进件 / 海关报关等扩展能力，支持产品选型、示例代码指引、业务速查、质量评估、答疑排障五大能力，并支持中文、English、日本語、한국어、Français、Español、Português、Русский、العربية **九语言**自适应作答。

### 谁该用这个 Skill

境外接入有「机构」和「直联商户」两种角色：

- **机构**（请求体带 `sp_mchid` + `sp_appid` + `sub_mchid`）——可直接收款、为子商户进件、做跨境分账、推送海关报关。
- **直联商户**（请求体带 `mchid` + `appid`）——**仅中国香港地区**允许，其余所有国家和地区的商户均须通过机构接入。

> 本 Skill 所有文档以**机构视角**撰写，适用于跨境电商、海外线下门店、海外 APP / 小程序、订阅扣款等出海收款场景。

### 五大能力

本 Skill 通过一张路由表把用户问题分流到对应文档模块，五大能力如下：

- **产品选型** — 根据出海业务场景（线下 POS / 无 POS 门店 / PC 网页 / 移动 H5 / APP·小程序 / 订阅扣款）匹配并推荐合适的境外支付产品，并说明选型理由与接入模式
- **示例代码指引** — 根据用户索要的接口和开发语言，引导到官方接口索引与文档底部的内嵌示例（Java / PHP / Go），**不自行编写**以避免签名 / 加密 / 参数错误
- **业务速查** — 速查境外支付业务背景、钱包体系（大陆钱包 / 香港钱包）、机构分类、资金流转、结算币种等核心概念
- **接入质量评估** — 以金融支付专家视角扫描接入代码，覆盖签名验签、回调处理、查单兜底、资金链路等常见质量问题，输出问题清单和修复方向
- **答疑与排障** — 解答接入中遇到的各类问题，按错误码或现象定位原因并给出方案，排障后主动推荐质量评估一次性排查潜在隐患

### 1. 产品选型

**能解决什么问题**：当开发者确定要做境外收款后，帮你在 7 大支付产品中根据**商户形态 + 用户终端 + 扣款模式**匹配合适的产品组合，并说明接入模式（直联还是机构）与结算币种规则。

**举个例子**：
- "我在加拿大开了线下实体店，没有专业 POS，应该用什么收款？"
- "我们是跨境电商 PC 官网，该选 Native 还是 H5？"
- "做海外订阅制 SaaS，要周期扣款，用哪个产品？"

### 2. 示例代码指引

**能解决什么问题**：当开发者需要某个接口的调用方式时，帮你定位到官方 `接口索引`，并引导到官方文档底部的内嵌示例代码。


**举个例子**：
- "境外 JSAPI 下单接口怎么调？给我调用方式"
- "`/v3/global/transactions/native` 的请求参数有哪些？"

### 3. 业务速查

**能解决什么问题**：快速厘清境外支付与境内支付的核心区别，以及跨境特有的业务概念。

**举个例子**：
- "境外支付的资金是怎么流转的？大陆钱包和香港钱包有什么区别？"
- "结算币种能自己选吗？我的子商户在日本注册。"
- "什么是融合机构、纯跨境机构？"

### 4. 接入质量评估

**能解决什么问题**：在上线前以金融支付专家视角扫描接入实现，覆盖安全合规、资金链路与业务常见质量问题，给出问题清单和修复方向。

**举个例子**：
- "我要上线了，帮我检查一下签名验签和回调处理有没有坑"
- "查单兜底和 `USERPAYING` 轮询逻辑这块我做得对不对？"

### 5. 答疑与排障

**能解决什么问题**：解答境外接入中遇到的各类问题，根据错误码或问题现象定位原因并给出解决方案。

**举个例子**：
- "调起支付报 `chooseWXPay:fail`，前端该怎么配？"
- "境外回调一直收不到 / 验签失败，怎么排查？"
- "子商户进件、跨境分账、海关报关报错了"

> ‼️ 排障完成后，本 Skill 会**主动推荐接入质量评估**，趁排障契机一次性排查其他潜在问题。
